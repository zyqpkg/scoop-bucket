# zyqpkg scoop bucket

A personal [Scoop](https://scoop.sh/) bucket for Windows apps not available in official buckets.

## Add this bucket

```powershell
scoop bucket add zyqpkg https://github.com/zyqpkg/scoop-bucket
```

## Install an app

```powershell
scoop install zyqpkg/<app-name>
```
